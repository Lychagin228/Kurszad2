## 🔧 Реализованные функции

### 1. `double f(double x)`

Назначение: Вычисление значения кусочной функции для заданного аргумента x.

Параметры:

x - аргумент функции, тип double.

Возвращает: значение функции f(x) в точке x, тип double.

Алгоритм: Проверяет условие x < -2, если истинно - вычисляет atan(2*x). Иначе проверяет x < 0, если истинно - вычисляет (e^x - x - 1)/(x*x). Иначе вычисляет sqrt(x*x + 4).

### 2. `int menu()`

Назначение: Вывод на экран главного меню программы с перечнем доступных операций.

Параметры: отсутствуют.

Возвращает: choice в случае успешного выполнения.

Алгоритм: Выводит форматированное меню с семью пунктами операций.

### 3. `int tablica(double start, double end, double step)`

Назначение: Формирование и вывод таблицы значений функции на заданном интервале.

Параметры:

start - начало интервала, тип double.

end - конец интервала, тип double.

step - шаг табуляции, тип double.

Возвращает: 0 в случае успешного выполнения.

Алгоритм: В цикле от start до end с шагом step вычисляет значение функции для каждого x и выводит пару (x, f(x)) в форматированной таблице.

### 4. `double integral_with_n(double a, double b, int n)`

Назначение: Приближенное вычисление определенного интеграла методом средних прямоугольников.

Параметры:

a - нижний предел интегрирования (начало интервала), тип double.

b - верхний предел интегрирования (конец интервала), тип double.

n - количество разбиений интервала интегрирования (целое положительное число), тип int.

Возвращает: приближенное значение определенного интеграла ∫[a,b] f(x) dx, тип double.

Алгоритм:

Вычисляет точность интегрирования h = (b - a) / n.

В цикле от i = 0 до n-1:

Вычисляет координату середины i-го отрезка: x = a + (i + 0.5) * h.

Вычисляет значение функции f(x) и добавляет его к накапливаемой сумме.

Возвращает результат: сумма значений функции, умноженная на шаг h.

### 5. `double poisk_x(double y, double eps, double start, double end, double step)`

Назначение: Поиск аргумента x, при котором значение функции приближенно равно заданному y с заданной точностью.

Параметры:

y - целевое значение функции, тип double.

eps - допустимая абсолютная погрешность, тип double.

start - начало интервала поиска, тип double.

end - конец интервала поиска, тип double.

step - шаг поиска, тип double.

Возвращает:

Найденное значение x, если решение найдено на заданном интервале.

Специальное значение 10000.0, если решение не найдено.

Алгоритм:

В цикле от start до end с шагом step:

Вычисляет значение функции f(x).

Вычисляет абсолютное отклонение |f(x) - y|.

Если отклонение меньше eps, возвращает текущее значение x.

Если цикл завершился без нахождения решения, возвращает 10000.0.

### 6. `double proizvodnaya(double x)`

Назначение: Вычисление приближенного значения производной функции в точке с использованием глобальной точности.

Параметры:

x - точка, в которой вычисляется производная, тип double.

Возвращает: приближенное значение производной, тип double.

Алгоритм:

Вычисляет оптимальный шаг дифференцирования на основе глобальной точности: h = pow(global_eps, 1.0/3.0).

Использует метод центральной разностной производной: f'(x) ≈ (f(x+h) - f(x-h)) / (2h).

### 7. `int tablica_to_file(double start, double end, double step, const char* filename)`

Назначение: Сохранение таблицы значений функции в текстовый файл.

Параметры:

start - начало интервала, тип double.

end - конец интервала, тип double.

step - шаг табуляции, тип double.

filename - имя файла для сохранения, тип const char*.

Возвращает: 1 в случае успеха, 0 в случае ошибки.

Алгоритм:

Открывает файл с указанным именем для записи.

В цикле от start до end с шагом step вычисляет значение функции f(x) для каждого x.

Записывает пары (x, f(x)) в файл в форматированной таблице с заголовком.

Закрывает файл.

### 8. `double integral_with_eps(double a, double b)`

Назначение: Приближенное вычисление определенного интеграла методом средних прямоугольников с использованием глобальной точности.

Параметры:

a - нижний предел интегрирования, тип double.

b - верхний предел интегрирования, тип double.

Возвращает: приближенное значение определенного интеграла ∫[a,b] f(x) dx, тип double.

Алгоритм:

На основе глобальной точности global_eps вычисляет оптимальное количество разбиений: n = (b - a) / sqrt(global_eps).

Вызывает функцию integral_with_n(a, b, n) для вычисления интеграла.

### 9. `int integral_to_file(double a, double b, const char* filename)`

Назначение: Сохранение результата вычисления интеграла в текстовый файл.

Параметры:

a - нижний предел интегрирования, тип double.

b - верхний предел интегрирования, тип double.

filename - имя файла для сохранения, тип const char*.

Возвращает: 1 в случае успеха, 0 в случае ошибки.

Алгоритм:

Вычисляет значение интеграла с помощью функции integral_with_eps(a, b).

Открывает файл с указанным именем для записи.

Записывает в файл параметры интегрирования, используемую точность и результат вычисления.

Закрывает файл.

### 10. `int poisk_x_to_file(double y, double eps, double start, double end, double step, const char* filename)`

Назначение: Сохранение результата поиска аргумента в текстовый файл.

Параметры:

y - целевое значение функции, тип double.

eps - допустимая абсолютная погрешность, тип double.

start - начало интервала поиска, тип double.

end - конец интервала поиска, тип double.

step - шаг поиска, тип double.

filename - имя файла для сохранения, тип const char*.

Возвращает: 1 в случае успеха, 0 в случае ошибки.

Алгоритм:

Выполняет поиск с помощью функции poisk_x(y, eps, start, end, step).

Открывает файл с указанным именем для записи.

Записывает в файл параметры поиска, результат и статус выполнения.

Закрывает файл.
